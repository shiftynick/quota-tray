# Code of conduct

We want Quota Tray to be a welcoming, practical open-source project.

Participants are expected to:

- be respectful and constructive;
- focus criticism on ideas and code, not people;
- avoid harassment, discrimination, threats, or unwanted personal attention;
- protect private information and credentials; and
- accept reasonable moderator decisions.

Project maintainers may edit or remove contributions and restrict participation
when behavior harms the community. Serious or repeated concerns should be
reported privately to the repository owner through GitHub.

This code of conduct applies in project spaces and when representing the
project elsewhere.
